# Asset Inbox

Temporary landing area for new uploads.

## Intake Steps

1. Place new files here.
2. Identify source, shot, version, and whether the file is original, reference, plate, element, or review media.
3. Rename only curated copies, not irreplaceable originals.
4. Move curated copies to their home: the shot folder if one shot uses them, `characters/<name>/` or `source/` if they are project-wide (`AGENTS.md`, Where Things Live).
5. Update the relevant manifest, bible, or shot note with the file path and notes.
