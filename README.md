# AI Video Workflows

Workspace for an AI-assisted VFX pipeline for the short film. Core principle: keep plates untouched and generate separable character and effect elements for compositing.

Start here:

- `AGENTS.md`: rules, where things live, how records are kept.
- `docs/worklog.md`: what was done in each session (newest at the bottom).
- `shots/`: one folder per shot; shot 004 (`shots/shot004_fire-jump/README.md`) is the active one.
- `docs/decisions.md`: project-wide decisions, dated.
- `docs/workspace-map.md`: the folder tree in more detail.

Characters: `docs/character-bible.md` (shared rules and the index), `docs/jerry-character-bible_v001.md` and `docs/tom-character-bible_v001.md` (frozen editions), `assets/characters/jerry/character-bible-v001/` (Jerry's reference set).
