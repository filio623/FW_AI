# Assets

Source and curated production assets for the short film.

## First Stop

Put new uploads in `assets/inbox/` first unless the destination is obvious. After review, move or copy them into the appropriate folder below and update `docs/asset-inventory.md`.

## Structure

- `inbox/`: unsorted uploads waiting for review.
- `scripts/`: screenplay drafts, locked scripts, and script breakdowns.
- `storyboards/`: storyboard frames, boards by sequence, and animatics.
- `plates/`: original plates, organized copies, technical proxies, and shot folders.
- `elements/`: separable VFX elements such as fire, water, smoke, steam, splash, mattes, scorch, contact light, and shadows.
- `characters/`: character reference, approved stills, expression/action sheets, and model training candidates.
- `references/`: external visual, style, and motion references.
- `audio/`: music, dialogue, scratch tracks, sound effects, and temp audio.
- `editorial/`: EDLs, XMLs, reference exports, and edit-facing notes.

## Naming

Use shot-first names for shot-specific files:

`shot004_fire-jump_plate_main_v001.mov`

Use character or purpose first for reusable material:

`jerry_fire_turnaround_ref_v001.png`

Keep original uploads untouched when possible. Put cleaned, transcoded, renamed, or extracted versions in the structured folders.
