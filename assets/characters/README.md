# Characters

Character-specific source and reference assets.

## Folders

- `jerry/`: fire character reference and generated assets.
- `sally/`: water character reference and generated assets.
- `tom/`: supporting character reference and generated assets.
- `wind/`: wind character reference and generated assets.

Each character folder can hold:

- `approved/`: approved look references.
- `expressions/`: face and emotion references.
- `actions/`: pose and motion references.
- `training-candidates/`: reviewed stills that may be useful for LoRA, Soul, or other model setup.

Mirror durable identity decisions in `docs/character-bible.md`.
