# Jerry Character Bible v001 Reference Set

Date assembled: 2026-05-19

Purpose: one clean location for the Jerry references approved or retained during Robbie's first character-bible review.

## Folders

- `references/primary-body/`: approved core body/look references. Use these first.
- `references/motion-poses/`: approved motion and pose references.
- `references/material/`: approved material reference.
- `references/secondary-training/`: useful support/training references that should not drive the primary look.
- `references/source-ref-only/`: source-render grounding references only.
- `references/performance-2d-ref-only/`: storyboard and 2D animation performance references only.

## Core Rules

- Jerry's base flame body is face-free.
- Do not bake in eyes, mouth, brows, nose, smile, or facial marks.
- Use 2D/storyboard references for personality and the separate face-animation layer only.
- Use primary-body references for shape, silhouette, and approved look.
- Use material/source references only as support, not as final body anchors.
