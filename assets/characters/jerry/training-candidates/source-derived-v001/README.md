# Jerry Training Candidates - Source-Derived v001

Jerry-focused frames and crops pulled from existing CGI renders, 2D animation, X-sheets, and storyboards, kept as possible future LoRA/Soul or other model training material. Listed in the parent `assets/characters/jerry/README.md` under `training-candidates/`. Not reviewed or approved look references; see `character-bible-v001/` for the approved set.

## Contents

- `animation/`: 9 Jerry-focused frames extracted from Scene 4A 2D animation (`scene4a_2d_animation_f####_jerry-focused.png`).
- `cgi-renders/`: 40 Jerry-focused frames extracted from CGI render sequences (`shot12tt_jerry5`, `shot12u_jerry5`, `shot4_ren_small_fire6`, `shot4_small_fire_extracted`).
- `sheets/`: 2 X-sheet expression sheets (`x_sheet_jerry01_expression-sheet.png`, `x_sheet_jerry02_expression-sheet.png`).
- `storyboards/`: 29 storyboard frames, split into `priority` (16, the main Jerry expression/pose set) and `secondary` (13, supporting frames) groups.
- `manifest.tsv`: per-file category, original source path, source frame, crop notes, and content notes for every file above.
