# Docs

Project-wide records. Shot-specific plans and logs are in `shots/`.

- `decisions.md`: register of project-wide decisions, dated (append-only).
- `worklog.md`: what was done in each session, with pointers (append-only). Start here to catch up.
- `findings.md`: lessons that apply beyond one shot (append-only).
- `asset-inventory.md`: index of curated media in `assets/`, including superseded and archived takes.
- `asset-intake.md`: how new media is classified out of `assets/inbox/`.
- `pipeline-strategy.md`: approach and tool roles.
- `workspace-map.md`: the folder tree in detail.
- `character-bible.md`, `jerry-character-bible_v001.md`, `tom-character-bible_v001.md`, `jerry-character-development-plan.md`, `tom-character-development-plan.md`: character look rules and plans; the `_v001` files are frozen editions.
- `archive/`: retired documents and older snapshots; nothing there is live (`archive/README.md`).
