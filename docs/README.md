# Docs

Project-wide records. Shot plans and logs are in `shots/`; character bibles in `characters/`.

- `decisions.md`: register of project-wide decisions, dated (append-only).
- `worklog.md`: what was done in each session, with pointers (append-only). Start here to catch up.
- `findings.md`: lessons that apply beyond one shot (append-only).
- `asset-inventory.md`: index of source media and what was restored from the NAS.
- `asset-intake.md`: how new media is classified out of `inbox/`.
- `pipeline-strategy.md`: approach and tool roles.
- `workspace-map.md`: the folder tree in detail.
- `archive/`: retired documents, older snapshots, and `restructure_2026-11-04_moves.tsv` (every path moved in the 2026-11-04 restructure); nothing there is live.
