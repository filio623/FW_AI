# Docs

Durable project decisions, setup notes, findings and production strategy. Most files are living documents with a version block and changelog (`AGENTS.md`, Document Lifecycle & Versioning).

## Contents

- `worklog.md`: what was done when, one dated entry per working session, with pointers. Start here to catch up.
- `findings.md`: dated observations and lessons (append-only).
- `pipeline-strategy.md`, `production-roadmap.md`, `comfyui-vfx-workflow-strategy.md`: approach and plan.
- `vfx-element-benchmark.md`: Pass A (Jerry element) test queue and every scored run.
- `asset-inventory.md`: index of curated media in `assets/`, including superseded and archived takes.
- `asset-intake.md`: how new media is classified out of `assets/inbox/`.
- `environment.md`: machines, tools and versions.
- `workspace-map.md`: where everything lives in the repo.
- `character-bible.md`, `jerry-character-bible_v001.md`, `tom-character-bible_v001.md`, `jerry-character-development-plan.md`, `tom-character-development-plan.md`: character look rules and plans. The `_v001` files are frozen editions.
- `AGENTS-CHANGELOG.md`: revision history of the root `AGENTS.md`.
- `archive/`: superseded versions and retired documents; nothing there is live (`archive/README.md`).
