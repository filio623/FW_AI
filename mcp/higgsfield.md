## MCP Candidate Requirements

A useful Higgsfield MCP should support:

- Account/status check.
- Model listing.
- Model parameter inspection.
- Cost estimation.
- Generation submission.
- Wait/poll.
- Output URL retrieval.
- Run log creation.
