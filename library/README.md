# Library

Research and records of material that lives outside the repo. Renamed from `references/` on 2026-11-04.

- `mickmumpitz/`: the Mickmumpitz Patreon workflow library, one folder per YouTube video, with `INDEX.md`. Workflows and guides are tracked; example packs and media stay local. Described in `mickmumpitz-library.md`.
- `mickmumpitz-library.md`: what the library holds, where it came from, and how to refresh it.
- `manifests/`: inventories of the external production drive and NAS, the Jerry asset review, and the Mickmumpitz Patreon manifests. Any move to or from the NAS updates its manifest.
