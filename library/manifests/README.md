# Manifests

The durable record of files that live off-repo. When media moves to or from cold storage, the matching manifest is updated in the same change (`AGENTS.md`, Cold Storage).

## Contents

- `external-drive_inventory_v001.md`: the external production drive.
- `jerry_external-drive_reference_inventory_v001.md`, `tom_external-drive_reference_inventory_v001.md`: Jerry and Tom reference material on the drive.
- `jerry_character-bible_asset-review_v001.md`: the asset review behind the Jerry character bible. Its `outputs/review/` paths no longer exist; outputs are ephemeral.
- `mickmumpitz/`: the 2026-10-19 Patreon post manifest, YouTube video list and removed-files list used to build `library/mickmumpitz/`. The same three files are in `library/mickmumpitz/_meta/`.
