# Mickmumpitz library

Mickmumpitz Patreon workflows and guides, one folder per YouTube video (`<date>_<title>__<video-id>/`, with `free/` and `advanced/` tiers), and `_patreon-only/` for posts without a video. `INDEX.md` lists every folder and file.

- Tracked in Git: `.json`, `.md`, `.txt`, `.tsv` and helper scripts. Local only: `.zip` and `.7z` example packs, video, images and extracted `*EXAMPLE-FILES*` folders (rules in `.gitignore`).
- `_meta/`: the manifests the sorter used.
- Paid content: keep the repo private.
