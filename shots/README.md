# Shots

One folder per shot, `shots/<shotNNN>_<slug>/`, holding everything that belongs to that shot: docs (README, plan, logs), plates, reference, per-pass inputs, graphs and kept runs, comps, shot-only scripts and outputs. Project-wide material (characters, screenplay, library) lives outside `shots/` (`AGENTS.md`, Where Things Live).

- `shot004_fire-jump/`: Jerry's fire jump into the grass. Pass A (Jerry element), Pass B (grass fire), Blender comp.
- `_template/`: copy it to start a shot: `README.md`, `plan.md`, `comp_log.md`, `pass-x_layer/` (`README.md`, `log.md`).
