# Characters

One home per character, used by every shot. Shots point here and never copy from it.

- `character-bible.md`: shared style rules, relationships, and the index of per-character bibles.
- `jerry/`: the small flame main character. Frozen bible `bible_v001.md`, reference set, reviews, candidates, CGI rig.
- `tom/`: the large fire villain. Draft bible `bible_v001.md`, review packs, working references.

Each character folder holds its `README.md`, `bible_vNNN.md` (frozen editions), `development-plan.md`, and only the subfolders it actually uses (reference sets, approval reviews, candidates, `source-cgi/`, `training-candidates/`, `outputs/` for its own renders). New characters (Sally, Wind) get a folder when their first material arrives.
