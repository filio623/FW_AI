# Jerry

Jerry is the small flame main character.

## Documents

- `bible_v001.md`: the frozen Jerry character bible (moved from `docs/` on 2026-11-04). `development-plan.md`: the character-development track.

## Folders

- `source-cgi/`: existing CGI renders and extracted stills of Jerry.
- `higgsfield-candidates/`: Higgsfield-generated stills or videos under review.
- `look-references/`: curated external or generated references that define Jerry's body look, silhouette, material, and movement language.
- `approval-review/`: curated review packs for Robbie's final approval before promoting images into the bible.
- `character-bible-v001/`: assembled first-pass bible reference set after Robbie review.
- `fire-rig/`: the Blender fire-rig build log. `higgsfield-casting/`: the Higgsfield casting log. `outputs/`: Jerry's own renders (the fire-rig bake).

Nothing is approved as a separate anchor beyond the bible's reference set; `approved/`, `expressions/` and `actions/` get created when their first file arrives.
- `training-candidates/`: reviewed images that may later be useful for LoRA, Soul, or other model setup.

Mirror durable identity decisions in `characters/character-bible.md`.
